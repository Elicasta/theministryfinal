# Live Scripture Controller & Bible Bank

## What changes in The Ministry

The iPad teaching manuscript preserves the complete script. Scripture quotations in the Inner Healing sermon are now actionable without leaving the transcript.

- Tap the scripture itself or **Project + Side TV** to send the exact KJV passage to the main projector while updating the side-screen Scripture independently.
- Tap **Side TV** to update only the persistent side-screen passage without interrupting the current main slide.
- Tap **Full Chapter** to jump to that book/chapter inside the new Bible Bank.
- In **Full Bible Bank**, type any canonical book and chapter (such as `Romans 6` or `2 Corinthians 10`), browse every KJV verse, and send any selected verse. Previous/next chapter controls stay in the same book.
- If the chapter source fails, *only lesson-saved verses* are shown, explicitly marked incomplete; the app does not claim that an abbreviated excerpt is an entire chapter.
- Existing sermon and teaching slides remain manually controlled, and prior archived lessons are unchanged.

## Side screen rules

1. Scripture remains on side TVs until a new scripture is sent or **Clear Scripture TV** is selected. Moving to an ordinary sermon slide must not replace the passage with a commentary card.
2. The side-screen layout shows **Spanish above English KJV**. Without authorized Spanish, it displays a clear RVR1960 connection/error message alongside the actual English text, never a mislabeled English translation.
3. Every scripture push increments `scriptureRevision`; out-of-order Spanish responses are ignored.
4. Cross-device messages reject old or duplicate timestamps. Cloud state writes are serialized, so a late response from an old write cannot overwrite a newer verse.
5. Scripture from the manuscript is parsed into book/chapter/verse and exact quoted text, including spans.
6. On successful RVR1960 retrieval, the TV displays the source's copyright notice and reports Fair Use Management (FUMS) activity.

## RVR1960 setup

The Ministry project currently has no API.Bible key or RVR1960 license configured. To enable exact RVR1960:

1. Obtain an API.Bible account with explicit access to Reina-Valera 1960. Review the applicable content and projection permissions.
2. Add `API_BIBLE_KEY` as a **server-only** Vercel environment variable for `theministry`. Do not publish the value or pass it through `/api/config`.
3. If available, set `API_BIBLE_RVR1960_ID` to the exact licensed Bible ID from the API.Bible dashboard. Otherwise the app attempts to find RVR1960 in the accessible Spanish Bibles.
4. Redeploy and test `/api/scripture?mode=spanish&ref=Psalm%20147%3A3`. Expect `ok:true`, `translation:RVR1960`, nonempty `text_es`, and attribution.
5. Open the iPad presenter and side screens on separate devices. Send Psalm 147:3, then Romans 6:16, then Jeremiah 6:14. Check text and reference change every time. Return to an ordinary slide and confirm the side screen still shows the latest passage.

Copyrighted RVR1960 text is loaded on demand from the licensed provider and is not committed into repository JSON. In the meantime, the public-domain KJV chapter browser and English-side output remain functional.

## Production smoke test

- Open `/presenter?lesson=inner-healing-2026-10-25` on iPad.
- Open `/projector?lesson=inner-healing-2026-10-25` and `/scriptures?lesson=inner-healing-2026-10-25` on other devices.
- Tap 2 Corinthians 10:5 in the manuscript: it should display immediately on projector and update the side screen.
- In the Bible Bank enter `Romans 6` and select verse 16, then verse 17. Side-screen reference and content must change on each tap.
- Press **Next** to resume the sermon. The side screen must preserve Romans 6:17.
- Tap **Clear Scripture TV** and confirm the blank waiting state persists.
- Temporarily disconnect the iPad network, reconnect and verify sync; send two verses rapidly and confirm the **last** verse wins.
- Run `npm test`, including `tests/live-scripture-bank.test.mjs`.

## Known source limitations

The full chapter browser needs network access to bible-api.com. API.Bible provides licensed RVR1960 only if the relevant version is authorized for the configured account. The translation is never generated by an LLM or substituted with an unlabelled variant.
